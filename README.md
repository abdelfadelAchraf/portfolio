# My Portfolio

This is my personal portfolio built with React and Vite.

## Features

- **Responsive Design**: Optimized for both desktop and mobile devices.
- **Smooth Scrolling**: A smooth scrolling effect when navigating between sections.
- **React Components**: Modular and reusable components for a clean codebase.

## Technologies Used

- **React**: JavaScript library for building user interfaces.
- **Vite**: A fast build tool that enhances development experience.
- **Tailwind CSS**: A utility-first CSS framework for fast UI development.

## Installation

1. Clone the repository:

    ```bash
    git clone https://github.com/abdelfadelAchraf/portfolio.git
    ```

2. Install dependencies:

    ```bash
    cd portfolio
    npm install
    ```

3. Run the development server:

    ```bash
    npm run dev
    ```

Your portfolio will be available at `http://localhost:3000`.
